# Code review of the DiagramBlock fence line and CommonMark fence rules (quire-rs PR 673)

## Summary

Ticket: PLAT-1682. Code review with the Rust lane (rust-review, rust-style) over
`git diff origin/main...HEAD` at 713efca9 (4 files, +193/-64): the new
`DiagramBlock.line`, the shared `walk::Fence` type, and the heading walk and
diagram scanner moved onto it. The line arithmetic is correct and panic-free and
the CommonMark length, character, info-string and closing rules are right for
top-level fences. The defects: `query.rs` still holds a second fence
implementation with different rules, fences nested in list items are no longer
seen, and there are stale docs and some smaller points.

## Verdict

**FAIL** because of FND-001, a second implementation of the fence rule, which
code-review records as `high`. Everything else is medium or low. What passed:
frontmatter, BOM and CRLF line offsets are right by construction (`skipped` is a
prefix of `raw`, `body` is a suffix, and newlines are counted). `fence_run` cannot
panic, because the slices fall on ASCII boundaries. A CRLF `\r` is absorbed by
`rest.trim()` and `\s*`. A backtick info string with a backtick, a tilde info
string with a backtick, and an unclosed fence all behave correctly. Gates on the
head: `cargo fmt --check` clean; `cargo clippy --lib --tests -D warnings` clean;
`cargo test --lib -- query:: parser:: extract::` 188 passed;
`cargo test --test it -- parser semantic_boundary spec_dogfood corpus_case
trace_dogfood` 132 passed. Consumer impact of the walk change, measured with a
Python mirror of the old and new `walk_headings` over 66,241 Markdown files under
~/dev: 42 files change their heading set, none under `spec/`, and each change
matches CommonMark (38 service READMEs where a stray `` ```bash `` used to close
a fence, two copies of a reviewer SKILL.md with a `` ``` text `` line, and two
quire-exact SR files with a four-space-indented fence inside YAML). No external
crate in ~/dev uses `DiagramBlock`, `extract_diagrams` or `walk_headings`. No
vendoring, pins or SHA ceremony was added.
