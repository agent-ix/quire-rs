## Summary

Post-ship gap analysis of the #90 umbrella program — CR-045..CR-049, landed as
PRs #96/#97/#99/#101/#102/#103/#104 (quire-rs v0.23.0→v0.25.0), quire-cli
#25–#29 (v0.16.0/v0.17.0), quoin #83. Steps 1–3 of the gap-analysis procedure
were run; the optional semantic review (step 4) was **skipped** — not opted
into.

**Plan completion.** N/A — the program was run ticket-only (umbrella #90,
children #91–#95); no plan bundle exists for it. The only bundle in `plan/`
(Plan-001) belongs to the previous program and its staleness is recorded as a
pre-existing finding, not attributed here.

**Matrix verification.** The 499/499 headline reconciles mechanically: 499
defined non-retired ACs, 499 audited with a covering TC, arithmetic chains
cleanly across the five CR entries in `spec/log.md`. All 12 program TCs
(TC-807..TC-818) are backed by real tagged tests. However 499/499 measures
AC→TC *mapping*, not verification — 271 of 490 TC rows are 🚧 — and four
non-program rows claim ✅ with no test in any tag form (FND-010).

**Underspecified code.** Two unowned behavior changes shipped inside the
program: `glossary_terms` silently narrowed its heading match (FND-007), and
`parse_body`'s panic contract is enforced by prose only (FND-001). The
declaration-driven selection path fails open in two shapes that reproduce the
CR-045 silent-un-minting class (FND-006).

An accompanying code review ran over the same diffs; its findings are folded
into the table below. Every finding is tracked: umbrella **#106**, children
#107–#115, quire-cli#30/#31, quoin#84 — all on board 18.

## Verdict

**FAIL** — high findings stand (FND-001..FND-005). The program's own matrix
rows are clean and its shipped behavior verified end-to-end, but the safety
properties three of its CRs rest on (byte-identity gate, FR-024-AC-9
replacement mitigations, the TC-813 pin) are either unenforced or pin nothing,
and one public API added by CR-046 can panic against FR-005's explicit no-panic
contract. Re-run this analysis once #107–#110 and quire-cli#30 close; the
residual mediums support CONDITIONAL at that point.
