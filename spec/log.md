* **2026-08-19** — **CR-079**: new [FR-062](./functional/FR-062-implements-relation.md) — the **requirement→production-code** relation (agent-ix/quire-rs#171).   **Two relations, no path between them.** `verifies` means *"this test would fail if the behaviour broke"* and may back an acceptance criterion; `implements` means *"this code is what the requirement is about"* and never may. This adds a field to an existing key rather than a fourth P2 manifest key.

  **The number is the t-way tuple count, deliberately not a covering-array size.** The minimum array size is NP-hard and depends on the generator; the tuple count is a property of the declared space alone, which is what an obligation must be able to restate from the spec later without knowing what tool ran. Forbidden combinations are first-class and bite at every strength above their own width: counting a combination that cannot exist makes the target permanently unreachable, which is the fastest way to get a coverage number ignored.

  Three ways to declare nothing are all rejected — strength 0 at load, fewer than two real dimensions mints nothing, and a strength above the dimension count counts 0 rather than the full product. Each would otherwise read as a declared space demanding coverage of nothing, which is worse than absent because it looks answered. TC-925..933.

The assertion is in fact the better substrate, not the worse one — a property test needs a generator domain, a precondition and an oracle, and EARS supplies only the last two (*"the system shall X"* quantifies over one system, not over a domain), whereas a quantified assertion carries all three: the determiner is the quantifier, the restrictive relative clause is the precondition, and the predicate is the oracle. FR-052 therefore classifies every criterion the `ac` grammar already binds to into a **closed** property-shape enum (`RoundTrip`, `Idempotence`, `Ordering`, `Invariant`, `Universal`, `ErrorCase`, `Lifecycle`, `Concurrency`, `Example`, `Unclassified`) under one **fixed total precedence** pinned in the spec rather than left to implementation, so structure outranks quantification and a universally quantified round-trip labels `RoundTrip`. For a `Universal` criterion it emits `{domain, precondition, oracle}` spans that are **statement-relative, never file-relative** (a supplement statement is synthesised by joining wrapped lines, so an offset does not index the file; only `line` is), and each span carries both byte offsets and its own text — offsets so the engine can assert the spans partition the statement, text because handing a UTF-16 consumer raw UTF-8 byte offsets is a defect generator, and the redundancy is checkable (FR-052-AC-6). Each record also carries `row_id` — without the criterion id the downstream generator cannot emit the tracking tag that coverage reconciliation keys on, and the chain would break silently — plus `signals`, the stable ids of what fired, which is the audit trail CR-019 asked for when it found the original sweep script had never been saved and the decision could not be re-derived. There is **no confidence float**: a float is unreviewable and invites the threshold tuning this program has already been burned by, so `Unclassified` is an explicit first-class outcome instead; and `extractable` is derived in exactly one place so the coverage column, any summary line and any downstream consumer cannot disagree about the ratio. `SchemaShaped` from the original report is **deliberately excluded** — its signal is repo state ("an OpenAPI schema exists"), not statement text, which would break determinism and corpus-comparability. Four constraints hold the boundaries: **CON-1** — classification never constructs a `GrammarFinding` and is never addressable by the FR-048 `grammar_severity` registry, so with no severity key there is no promotion path and `--strict` immunity holds by construction; a pass/fail gate on "is this criterion property-shaped" would invite authors to reword criteria to satisfy a checker instead of to describe the system, and it is the same failure mode as narrowing a check until its count looks comfortable. **CON-2** — the engine never names a test framework, harness or generator library; the shape→harness mapping belongs to the downstream `spec-correctness` work (quoin#46). **CON-3** — the shape enum is closed in the engine and extension happens by declaring idiom phrases, never by adding a shape, since a shape with no generator silently drops criteria. **CON-4** — a criterion's `extractable` value never depends on a module-declared idiom. That last one is the structural answer to whether the module `property_idioms:` registry is another open-set trap: CR-014's rule is that a closed set which *suppresses* is safe while an open set whose membership is *required* is not, which is what retired `no-observable-outcome` at ~13% sampled precision. Three of the four metamorphic classes are not actually open (invariant = English function words, idempotence = quantity adverbs, ordering = a small lexicon), and even round-trip has a closed structural signal — two operations composed plus an identity back-reference (`yields the input`, `returns the original`, `byte-identical`) — so **closed structural signals carry extraction coverage and the registry only refines labels**. A repo declaring nothing gets full reach; a missed idiom degrades a label to a less specific shape rather than dropping a criterion, and TC-790 pins that as a property test rather than an assumption. Also: [FR-047](./functional/FR-047-acceptance-criteria-grammar.md) gains a CR-028 note recording that `AcShape` is unchanged and **gains no variant**, and that the `ac` finding stream is **byte-identical** with the classifier present and absent (FR-052-AC-7), so every corpus figure in the notes above stands unmoved; [FR-050](./functional/FR-050-declarative-coverage-computation.md) gains a CR-028 note and **FR-050-AC-13** for the `criteria` field and the two new `CoverageTotals` counts, whose byte-identical guarantee under FR-050-AC-7 now covers content FR-050 does not otherwise describe. CR-020's recorded caution stands and is quoted verbatim in FR-052: StR criteria are validated by demonstration rather than quantified over an input domain, so they will legitimately score low on property-extractability and #20 must not read that as a quality failure. Adds FR-052-AC-1..13 + TC-779..791 and FR-050-AC-13 (TC-788, shared); every new TC ships 🚧 pending the engine slice; matrix 464/464.
