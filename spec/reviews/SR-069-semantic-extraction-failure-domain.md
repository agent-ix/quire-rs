## Summary

Applied the failure-domain checklist (trust boundaries, entity identity, evaluation purity, topological robustness) to the quire-rs#388 slice against the upstream `agent-ix/quoin` FR-070..FR-075 contract, its mapping fixtures, and the existing parser (`src/query.rs` `scan_fenced_blocks`, `src/parser/walk.rs`) and Filament boundary (`src/filament.rs`). The boundary itself is well guarded (offline, opaque fence bodies, additive outputs, explicit refusal codes), but thirteen failure modes are unstated: one high (a row-level error leaves the `fields` availability undefined, so a partial declaration set can reach the compiler as `available`), nine medium, three low. Verdict: not ready for `spec-to-plan` until FND-300..FND-304 are answered in FR-069/FR-070/FR-072.

## Proposed Additions

| Finding | Target | Proposed constraint |
| --- | --- | --- |
| FND-300 | FR-072 Behavior (FR) | Any `error`-severity diagnostic on a row or fence line SHALL set that declaration kind to `unavailable` with `reason` naming the code and locus; `available` SHALL mean every authored row produced an entry. |
| FND-301, FND-308 | FR-070 Behavior (FR) | Adopt the upstream resolution order verbatim and add `semantic.ambiguous-type` (title shared or bundle/import collision), `semantic.duplicate-field`, and the remaining reader-rule codes; add `nullable` to the keyword set or state its exclusion. |
| FND-302 | FR-070 Behavior (FR) | Define the placeholder token encoding (or refuse with `semantic.unresolved-type` at `error` when the token cannot form a valid identity) so an author error never reaches the engine-defect path. |
| FND-303 | FR-072 Behavior + FR-069 Inputs (FR) | State that single-document extraction resolves only kernel scalars and snapshot-supplied imports (with export lists), and record the resolution scope in the record (for example `resolutionScope: document \| corpus`) so the advisory is interpretable. |
| FND-304 | FR-069 Behavior (FR) | Add `semantic.import-unresolved`, `semantic.import-cycle`, and `semantic.duplicate-package` load failures, or state that the loader trusts install-time checks and applies none. |
| FND-305, FND-309 | FR-071 Behavior (FR) | Define ownerless fences, zero/multiple fences per heading, sub-headings, Operations-subsection fences, and the standalone `Clause:` line (refused, since following it is a read outside the document); scope duplicate ids across both sections; add `semantic.operation-name-not-identifier`. |
| FND-306 | FR-071 Outputs (StR integrity) | Derive `startColumn`/`endColumn` from the actual fence line (indentation and fence length), define the body as the bytes between the opening line's newline and the closing line exclusive with `\r` retained, and refuse an unterminated fence with a code. |
| FND-307 | FR-070 Behavior + CON-1 (StR purity) | State that `pattern` regexes are carried uncompiled, and give an escaping rule (or a quoting form) for `,`, `/`, and `\|` inside `pattern` and `enumValues` items. |
| FND-310 | FR-070 Behavior (FR) | Classify typed-first mixed sections as `semantic.properties-both-forms` or legacy, define an empty section as `unavailable` with reason, and refuse a second `## Properties` heading. |
| FND-311 | FR-072 Behavior (FR) | State that semantic `error` findings fail `quire validate` like other errors, that `advisory` is an additive severity value on findings, and that diagnostics are ordered by (line, column, code). |
| FND-312 | FR-069 Behavior (FR) | Resolve reference-form schemas from the inline schema map keyed by the manifest path (digest over the map bytes) and refuse a key absent from the map with `semantic.data-schema-missing`. |
